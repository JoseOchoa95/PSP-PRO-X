# PRO-X Internet update

Copy the matching PSP/GAME/PROUPDATE, FastRecovery and PROXUPDATE folders from this package, including cacert.pem, without deleting existing configuration, plugin lists, games or reports. With storage and AC connected and battery charge at least 50 percent, open PROUPDATE from Games, press X to install, wait for Done and press X to start PRO-X. Check Settings -> System Settings -> System Information shows the product version printed in the package manifest. Use the matching Fast Recovery after a complete shutdown when PRO-X is not already active.

For subsequent updates, open Settings -> System Update -> Update via Internet. The original PSP screens use the installed system language and theme. PRO-X checks the public GitHub catalog, excludes drafts/prereleases and equal/older versions, validates compatibility and verifies the exact manifest, package and allowed staged files over authenticated HTTPS before launching the target's existing PRO-X installer. An actual query failure remains an error. No Sony update service or firmware-writing engine is a fallback.

Checking does not require installation power or writable download storage after successful CFW/RAM initialization. Leave the matching local package available while PRO-X starts and allow ten seconds in inactive XMB for preparation; a missing client or failed initialization cannot be treated as a successful no-update check. This is not cold boot or installation without storage. After a newer compatible offer and download acceptance, storage, free space, AC and battery readiness are required and rechecked before handoff. Missing storage uses the original native storage message; missing installation power uses the original generic update-start error. Do not remove storage, disconnect power or suspend while downloading or installing.

The native checking/offer/progress screens are integrated with the system. The destination's existing installer still displays its text interface and requests X to install and X to start CFW after completion. A new native installer screen, single-confirmation installation and automatic restart are outside this release. Infinity and powered-on storage-reinsertion routing have not been validated as part of this change.

Hardware evidence is limited to owner-reported tests recorded in the package manifest and release notes. Supported models are restricted by the OTA manifest; do not infer universal compatibility. Future eligible stable releases must include their matching pro-x-update.json and dedicated update ZIP. Preserve native-report-NNN.txt, native-download-NNN.txt, dispatch.txt, launcher.txt and install.txt when present after an error. A cardless check cannot leave a trace file on an absent card. Packaging does not publish a release or authorize Git operations.
