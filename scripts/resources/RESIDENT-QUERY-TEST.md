# PRO-X v@PRODUCT_VERSION@ resident query test

This is a local query-only diagnostic for a PSP-2000 with system software 6.61 and model ID 1. The manual Installer provisions the matching user-mode query module in a build-specific flash0 file and verifies its bytes before installing the ordinary CFW modules. Settings reads only that internal worker and its compiled trust bundle. It checks GitHub through the original PSP screens. Internet download and installation are disabled in this diagnostic.

1. Save your current working Installer and Fast Recovery. Copy the matching `PROUPDATE` and `FastRecovery` folders from the ZIP into `PSP/GAME`. The manual Installer has no charger or minimum battery level requirement. Leave the card inserted during installation.
2. Open the Installer from Games and press X. It reports the free, required and allocation-unit byte counts for flash0 before any firmware writes. On the first provision, expect `Resident query worker verified.` and then `Completed.`. Press X again to activate PRO-X. If the Installer reports a failure, preserve the message and exit. Keep the known working manual package for recovery.
3. Fully shut down. Start the PSP and activate PRO-X using this kit's Fast Recovery with a card that has no `PSP/GAME/PROXUPDATE` folder. If you reuse the installation card, preserve or rename its existing `PROXUPDATE` folder. Check `6.61 PRO-X @PRODUCT_VERSION@` in System Information.
4. In Settings, select **System Update → Update via Internet** and your usual Wi-Fi connection. With the current public catalog, expect the original latest-version message after an authenticated check. Run it twice more. Send `PROXDIAG/dispatch.txt` and the new `PROXDIAG/native-report-*.txt` from the card. The dispatch should include `resident flash0 image verified and loaded` on the first query after activation. Later queries reuse the worker.
5. For a separate no-card check, fully shut down and restart with the Fast Recovery card, activate PRO-X, then remove the card while no I/O is active **before the first System Update check**. Report the exact menu result. Report files are optional, so a no-card check depends on the visible result. Reinsert the card only when the PSP is off. A normal suspend/resume and repeated check with the card present may be tested separately.

For manual recovery, reinstall the earlier working PRO-X package with its own matching Installer and Fast Recovery. The diagnostic worker occupies only its build-specific internal file. The old VSH ignores that file. Stop after an installation error and preserve its message for review. Use the normal shutdown path only after the installation or query has finished.

The optional completion-resource provision test requires the exact owner-supplied original 6.61 `native-completion.rco`. For that test only, place it next to the manual Installer at `PSP/GAME/PROUPDATE/native-completion.rco`. A new provision displays `Original completion resource verified and stored.` The Installer verifies the original and stores only the compact original phrases. The supplied file may be removed after successful provisioning. The diagnostic ZIP ships no original resource. This kit tests provisioning and query behavior. Native rendering and the dedicated update's complete write and restart remain separate tests.
