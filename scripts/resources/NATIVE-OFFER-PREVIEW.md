# Original PSP update offer — protected local preview

This v@PRODUCT_VERSION@ package is a diagnostic preview, not an available release or an installation candidate. It first performs the real authenticated GitHub catalog query using the tested native network path. Only after a successful no-newer-release result does it simulate a positive 1 MiB offer to exercise the PSP's original next screen. The public v0.3.1 release is still older and is not offered for downgrade. Query errors remain errors. The build manifest marks `simulated_positive_offer: true` and `production_ota: false`; no release is created or edited.

Original update_plugin file mutations are blocked before its entry runs: Open permits only PSP_O_RDONLY; Write, Rename, Mkdir, Chstat, Remove and Rmdir are denied, and ioctl/devctl permit only the inspected output-only media queries. Unknown/incomplete import layouts are rejected atomically. ReadData cannot supply an installer, and no package/installer is downloaded, executed or written by this preview. The worker still writes private diagnostic reports. Existing UPDATE files must remain untouched.

1. Keep the previously accepted query package and back up the memory card. Copy the three matching folders under PSP/GAME, including PROXUPDATE/cacert.pem. Preserve existing reports, settings and plugins.
2. With the memory card inserted, charger connected and adequate battery, open PROUPDATE (the PRO-X Installer) from Games. Press X to install, wait for Done, then X to start PRO-X. This loads the preview-specific provider and filesystem guards. Do not open the Games entry named PRO-X v@PRODUCT_VERSION@ System Update for this test.
3. Open Settings -> System Update -> Update via Internet. Select the usual connection and wait. After a successful real query, expect the original system screen stating that Network Update found a later version and giving its storage/download instruction. This offer is simulated and is not a real published version. Language/theme and system button mappings must come from the installed system.
4. First cancel from that offer and verify return to XMB. Repeat, then accept the displayed download action once. Expect a controlled storage/download error because native file creation and ReadData are blocked. It must not download/install, launch a Sony updater, hang or alter an existing UPDATE/EBOOT.PBP. Cancel/acknowledge the error to return to XMB. Stop if any unexpected installation starts.
5. Repeat the query and cancel again. Try one language or theme change if practical. Return PSP/GAME/PROXUPDATE/native-report-NNN.txt, dispatch.txt and the exact displayed text or a photo. Report which buttons you pressed, whether each action returned to XMB, and whether the shown storage requirement and layout look original.

The original stock offer message contains a free-space value and a download action; it has no built-in product changelog/charger text field. Filling version, release notes and prerequisites while keeping original widgets/localized labels remains integration work. The native one-consent download, secure installer handoff, reuse of the original standalone installer UI and automatic restart are not enabled by this preview. A consent-bound verified ZIP/staging backend is implemented and tested offline but is not invoked from this preview.

After the preview, restore the previously accepted native-query package and run its PROUPDATE Installer X/Done/X once to remove the preview-specific provider/guards. Merely overwriting the client does not replace resident VSH firmware. Keep both packages and reports until this milestone is evaluated. No Infinity changes, cardless installation, stable OTA assets or release publication are included.
