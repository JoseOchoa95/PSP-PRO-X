# PRO-X Memory Stick write trial

This standalone PSP 6.61 diagnostic tests one write on the backed-up 256 GB validation card with the original Memory Stick adapter. It requires the tested exFAT layout and stock driver code. The test sector is LBA 500694016, beyond the existing volume and inside the physical card. Use a card whose contents you can afford to lose. A defective adapter might direct a write to a different address.

1. Put the backed-up 256 GB card in the PC's **direct microSD reader**. Open administrator PowerShell. Use `Get-Disk` to identify the card's disk number, then run `py -3 .\mswrite-reference.py prepare N`, replacing `N` with that number. Preparation reads the card and saves the original target sector, a random marker and seven control fingerprints in a temporary `MSWTEST.BIN`. Keep the PC copy.
2. Copy `release/PSP` from this ZIP to the root of a working launch card. Place `MSWTEST.BIN` beside `EBOOT.PBP` in `PSP/GAME/MSWRITE/`. Launch **PRO-X Memory Stick Write Trial**. After the Memory Stick activity light goes out, insert the 256 GB test card with its original adapter.
3. Press **X** for the preview. The app checks the card and tests whether the stock driver grants a read/write handle. It shows the open result, number of handles and write protection state before offering any write. If it shows sector 500694016 and the confirmation prompt, press **L + R + X** with the same card still inserted to overwrite that single sector. Press **O** to cancel. Photograph the result, including any refusal and the state lines above it.
4. After the trial, connect the tested card directly to the PC and run `py -3 .\mswrite-reference.py verify N "<path-to-MSWTEST.BIN>"` with the current disk number and the PC copy. Share its result and the PSP photograph. The marker is left on the trial card for independent verification.

Successful PSP readback is preliminary. Independent verification must find the marker at the target and all recorded witness sectors unchanged. This trial cannot verify all possible aliases on an unknown adapter. It is a test of this card and adapter, not a partition creator or formatter.

The stock driver must accept read/write access while the filesystem volume is unmounted. The one-sector trial holds Sony's I/O mutex during the final media and sector checks and the write. A stable shared handle count is allowed because it counts open clients, including clients with no transfer in progress. The trial stops if the count changes before dispatch, the stock media state changes or the saved target data differs.
